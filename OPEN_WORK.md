# Canonical harness software backlog

## Completed source consolidation

The repository owns one governance runtime and its portable verification, plus
the independent Observatory package under `packages/harness-observatory/`.
`docs/architecture/software_consolidation.md` defines ownership and acceptance.
The aggregate verifier checks the kit, publication regressions, Observatory
source/dependency origins, synthetic tests, CLI, demonstration and exact
software-only publication inventory. Provider inputs are generated temporarily;
existing transcripts, evidence, analyses and old source histories are excluded.

Existing immutable releases retain their bytes and logical publisher identity.
Observatory is not installed into governance consumers or included in release
1.4.0. Changed shipped components require their own reviewed release.

The routing-analysis cleanup removes fixed historical comparison totals and
implicit project selection. Synthetic regressions verify explicit working
directory selection, input-derived report totals and the absence of literal
corpus comparison tables. Published history remains intact; source-content
review supplements the pattern and inventory gate.

## Remaining boundaries

Consumer updates require an explicit owner-approved private allowlist and their
own verifier. Historical adoption is not continuing update authorization.
Read-only or blocked repositories, tool-owned stores, worktrees, private data,
historical evidence and stronger product authorities retain their preservation
rules. Missing product contracts, held execution, unresolved Git identities and
incomplete discovery remain substantive acceptance gaps.

Private collection, reconstruction/measurement acceptance, bulk backfill,
semantic labels, live telemetry, optimization, scientific/model/platform
qualification and human acceptance remain separate work. Existing P1b/P1c/P6
continuation decisions remain in force. Source consolidation activates none of
those workflows and copies no private experiment findings into this backlog.
